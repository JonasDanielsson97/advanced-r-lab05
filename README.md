The goal of lab05 is to build an R package that uses an API to connect to the web. 
The package described here uses the Turf Game API, more specifically the turfgame API v 5 (current most updated stable version) described at 
https://api.turfgame.com/v5.

The package contains user-friendly functions to retrieve information about Turf Game statistics.
